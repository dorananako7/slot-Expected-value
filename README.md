# 天井／期待値チェッカー

## 使い方

`index.html` をスマートフォンまたはPCのブラウザで開いてください。サーバー、インストール、APIキー、インターネット接続は不要です（サイト内の参照元リンクを開く際にはネット接続が必要）。機種選択、条件、現在のG数、等価／5.6枚の公開表、47枚／160枚貸し、スルー数、本前兆フラグなどを設定できます。入力の保存にはブラウザのローカルストレージを使用します。

## 金額と計算条件について：重要

1. 期待値は解析媒体が**設定1などの一定の仮定で推定した参考値**であり、メーカー保証値・実測勝率・この店での期待収支を表しません。元資料の交換・ヤメ時・天井・コイン持ち・状態・前兆・閉店欠損の前提を必ず確認してください。
2. 店舗が公表したのは**貸しメダル**（1,000円/47枚、1,000円/160枚）であって、**景品交換率ではありません**。「等価／5.6枚」は解析媒体の表を選択するための設定です。47枚貸しの実際の円収支がその値になるわけではありません。
3. **160枚貸しでは期待値の円表示を無効化**しています。20円相当の公開期待値を金額だけ機械的に換算すると誤解を招くためです。
4. 出典表にないゲーム数を、**隣接する2点の間だけ線形補間**しています。表の範囲外を外挿したり、期待値のない別条件を推測したりしません。
5. **天井までの追加投資換算**は、残りG ÷ 50枚あたりの平均G数 × 50枚 × **貸しメダルの1枚あたり購入額** という単純な算術です。途中当選や持ちメダル、特殊カウントを考慮しないため、実際に必要な資金の予測ではありません。コイン持ち不明・液晶Gなど不適切な条件では非表示にします。
6. AT間、CZ間、周期、ポイント、液晶Gなど**別のカウンター**があります。台の実際の表示・履歴を確認してください。特に「転生2」「マギレコ」はサイトが示す**出典のG換算**と実際のあべし／ポイント数を混同しないでください。
7. 本前兆中など出典と条件が異なるときは金額表示を無効化します。スルー回数は記録可能ですが、**期待値表には反映されません**。ボーナス種別、リセット状態等は確認できた場合のみ切り替えてください。
8. P-WORLD掲載の残り85機種は検索・閲覧できますが、現在このファイルに信頼できる期待値表がないため「未収録」です。天井情報も補完済みではありません。

## ソースコードの構成

- `index.html`：HTML、CSS、JavaScript、解析表を**すべて内包**した完成品。これだけで動きます。
- `app.js`：`index.html` 内のJavaScriptと同じ内容の編集・閲覧用コピー（`index.html`から外部読込はしていません）。
- `roster-snapshot.json`：P-WORLD掲載の機種一覧を構造化した控え。
- `preview-mobile.png`, `preview-desktop.png`：画面確認用画像。

公開には `index.html` を GitHub Pages または既存の Nginx の公開フォルダに配置できます。著作権に配慮して解析元の文章・画像の転載は避け、数値の引用元へリンクしています。実装を変更したり再配布する際には元媒体の利用規約も確認してください。
