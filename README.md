# 123＋Nはりまや橋店 台チェック — 機種選択フィルター版

今回の更新は機種選択モーダルの情報フィルターのみです。期待値・出典・ゾーン・スルー・棒グラフ等の計算ロジックには変更を加えていません。

## 操作方法

「台を選択」→「機種を選択」で、検索窓の下に「すべて／計算できる台／計算できない台」タブと、3つのチェックボックスが表示されます。

- **ゾーン狙い情報あり**：資料由来の区間データ（開始・終了Gやpt、あべしなど）を登録済みの機種。
- **狙い目情報あり**：公開金額表にプラスの帯があるか、出典に基づいたスルー／周期天井の注目条件を持つ機種。利益保証ではありません。
- **期待値を計算できる**：少なくとも1つの条件で公開・参考の円期待値表を収録している機種。指定したゲーム数・条件で必ず金額が出るとは限りません。

複数チェックは AND 条件（すべて満たす機種）です。タブ・機種名検索とも併用できます。「条件をクリア」を押すと検索語・チェック・タブがリセットされます。機種ごとの表示タグも追加しました。

掲載機種は前回版の固定スナップショット（2026-11-04時点）です。自動更新はありません。
