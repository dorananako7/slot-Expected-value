## 今回の追加条件入力
- スルー回数、周期数、チェリー累計、専用カウンターなど、対象機種にのみ表示。
- 「不明」と「実機で0を確認済み」を区別します。未確認の状態では元記事の平均条件の表のみ使います。
- 具体的なスルー数を入力した場合、条件別の数値表がある機種・場面にのみ円期待値を表示し、未収録なら推定を避けて「算出不可」にします。
- 回数上限は**最深の規定条件**の確認用で、途中のモード当選やボーナス当選を排除するものではありません。
- 複数の状態を選択すると、該当する複合条件の公開表がない限り金額を算出しません。
